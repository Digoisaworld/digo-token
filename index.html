Register DIGO metadata

This is a separate step for an already-created SPL Mint. It registers the token name, symbol and logo URI with the Metaplex Token Metadata program. It cannot create a mint and it will not run automatically.

Required: an existing Mainnet SPL mint with 8 decimals, initial supply of 100 billion DIGO, and mint authority still controlled by the connected Phantom wallet.


Metadata URI currently points to the project's GitHub-hosted JSON. GitHub is convenient but does not guarantee permanent decentralized storage. The metadata account will remain mutable so the project can update its URI later.

Prepare DIGO Mainnet mint

This tool prepares one transaction containing mint-account creation, SPL Token initialization, your associated token account creation and the initial mint of 100 billion DIGO. It does not send anything until you separately approve the final action in Phantom.

Wallet: Not connected
Network: Solana Mainnet Beta
Token program: Original SPL Token
Decimals: 8
Initial supply: 100,000,000,000 DIGO
Mint authority: Your connected Phantom wallet
Freeze authority: None

Important: Mint authority will remain active, so total supply is not permanently capped. The mint keypair is generated in this browser session. Save the mint address shown after preparation; do not clear this page before the transaction is completed.
Connect the intended Phantom wallet to begin. No seed phrase or private key is needed.
