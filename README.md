# DIGO — AI × Solana

**DIGO** is a technology-focused project exploring practical coordination and payments for AI agents and digital services on Solana.

> Project status: the token exists on Solana Mainnet. The AI network, payment integrations and public swap are not yet demonstrated as production services. This repository's current GitHub API visibility is **private**; public access and Pages deployment must be enabled and verified by the repository owner.

## Proposed AI and technology utility
1. **DIGO Agent Hub** — discoverable directory of AI agents and tools.
2. **AI API Marketplace** — metered access to participating model, data and automation APIs.
3. **Agent Payments** — settlement between AI agents and service providers.
4. **Compute Integrations** — connections to independent inference/GPU providers.
5. **Developer SDK and Dashboard** — integrations, test tools, supply, treasury and usage transparency.

These are roadmap concepts, not live products or guaranteed sources of token demand. AI inference remains off-chain; Solana may provide settlement and verifiable coordination. See [AI_ARCHITECTURE.md](AI_ARCHITECTURE.md).
